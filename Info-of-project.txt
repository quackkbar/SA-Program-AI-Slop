2. ใช้ระบบอะไรรันบ้าง ดาต้าเบส ภาษาโค้ด อธิบายอย่างละเอียด

ระบบนี้พัฒนาเป็นแบบ Full-stack Web Application ระดับ Enterprise ตามสถาปัตยกรรมของ Next.js โดยมีองค์ประกอบทั้งหมดดังนี้:

1) Frontend & Web Framework (ส่วนแสดงผลและส่วนควบคุม):
Next.js 14 (App Router): เฟรมเวิร์กหลักของระบบ ทำหน้าที่เป็นทั้ง Web Server, การจัดการเส้นทางหน้าเว็บ (Routing), Server-Side Rendering (SSR) และ API Endpoints
React 18: ไลบรารีสำหรับสร้างคอมโพเนนต์ส่วนติดต่อผู้ใช้ (UI Components) และ State Management
Tailwind CSS: เครื่องมือจัดสไตล์หน้าเว็บ จัด Layout อัตราส่วน กล่องข้อมูล ตาราง และการตั้งค่าหน้ากระดาษ @page { size: A4 portrait } สำหรับพิมพ์เอกสาร A4 และบันทึกเป็น PDF
Lucide React: ชุดไอคอนแบบ Vector SVG ที่ใช้บนหน้าจอทั้งหมด (เช่น ไอคอนพิมพ์, ย้อนกลับ, ถังขยะ, เช็กถูก)
2) ภาษาคอมพิวเตอร์ที่ใช้เขียน (Languages):
TypeScript (.ts, .tsx): ใช้เขียนโค้ดหน้าเว็บทั้งหมด 100% ทั้งในโฟลเดอร์ app/ และ lib/ เพื่อตรวจสอบ Type ข้อมูล ป้องกัน Runtime Error
JavaScript (.js / .mjs): ใช้สำหรับไฟล์คอนฟิกของระบบ เช่น next.config.mjs, tailwind.config.ts, launch-desktop.js, prisma/seed.js
PostgreSQL SQL: ภาษาคำสั่งสำหรับสร้างตาราง, Foreign Key, Constraints, และ Views ในไฟล์ DDL
3) ฐานข้อมูลและการจัดเก็บข้อมูล (Database & Persistence Layer):

ระบบรองรับ 2 รูปแบบคู่ขนานกัน:

ฐานข้อมูลจริง (Production Mode): ใช้ PostgreSQL ร่วมกับ Prisma ORM (@prisma/client) มีสคีมาครบถ้วนตามไฟล์ prisma/schema.prisma
ระบบจำลองข้อมูลแบบออฟไลน์ (Client-Side Storage Mode): มีระบบจัดการข้อมูลผ่าน localStorage ใน lib/storage.ts ซึ่งจะทำงานอัตโนมัติ ทำให้สามารถเปิดเว็บ ทดสอบ เพิ่มคำสั่งซื้อ ออกใบเสนอราคา ออกใบเสร็จ และดูรายงานยอดได้ทันที โดยข้อมูลไม่สูญหายแม้ไม่ได้เชื่อมต่อกับ PostgreSQL Server ภายนอก
4) Runtime Environment:
Node.js: รันบน Node.js (เวอร์ชัน 18 ขึ้นไป หรือ 20+)
